# Dictionary: UDL ↔ physics

| UDL term | Data-engineering meaning | Physics counterpart | How close |
|---|---|---|---|
| **Universal Data Lake** | Raw, unstructured storage, read with a schema chosen at query time | Space / the vacuum of quantum fields; in H5, the substrate geometry emerges from | Metaphor |
| **Read / query** | Retrieving data in a chosen schema | Measurement or recorded interaction, in a chosen basis | Close |
| **Schema-on-read** | Structure applied when data is read | Observable chosen by the measurement setup; outcome undefined until then | Close |
| **Inode** | One file's data and metadata | A quantum state (state vector) | Close |
| **Hard link** | One of several names pointing to the same inode | A branch of a superposition, e.g. "particle at slit 1" | Close, with weights |
| **Link weight** | (not standard) | Complex probability amplitude | Needed for interference |
| **Read follows a link** | | Born rule: probability = \|amplitude\|² | Exact if weights are amplitudes |
| **Unlinking the others** | Removing other directory entries | Collapse / state update after measurement | Close |
| **Inode shared by two machines** | | Entangled state of two systems | Close |
| **Local view of a link** | What one machine sees without the other | Reduced density matrix (partial trace) | Exact: for a maximally entangled pair, pure noise |
| **Commit on first read** | Transaction fixing a value | Measurement on one subsystem | Close |
| **Cross-shard constraint** | CHECK linking two shards | Correlations of an entangled state | Close |
| **Replica** | Copy with its own stored values | Local hidden variables | **Ruled out** by Bell tests |
| **Copy** | Duplicate of the data | Cloning a quantum state | **Forbidden** (no-cloning theorem) |
| **Writable commit** | First reader chooses the value | Superluminal signalling | **Forbidden** (no-signalling) |
| **Lake capacity** | Storage limit per volume | Bekenstein bound: max information ∝ boundary area | Open question, see 05 |
| **Property of the lake** | Behaviour of the store itself, not of the data | Gravity / spacetime geometry in H5 | Hypothesis |
| **Medium that behaves like spacetime** | | Analogue gravity (water, light in fibre, BEC) | Demonstrated in the lab |
